## ㉕ Lesson / 10月2日
**テーマ：学生時代の話 / 性格タイプの語彙**
講師：Louise（フランス出身・25歳）

### 🎯 語彙①：学生タイプ・性格（今回のメイン）
**What kind of student were you?**（どんな生徒だった？）

| 英語 | 日本語 | 補足 |
|---|---|---|
| class clown | クラスのお調子者 | ムードメーカー。みんなを笑わせる子 |
| bookworm | 本の虫 | someone who likes reading の言い換え |
| teacher's pet | 先生のお気に入り | 少し皮肉っぽく「ひいきされてる子」のニュアンス |
| troublemaker | 問題児・トラブルメーカー | 普通は1語で書く（メモは trouble maker） |
| class leader | クラスのリーダー | 学級委員的な存在 |
| sleepy student | 眠そうな生徒 | |
| lazy student | 怠け者の生徒 | |
| friendly student | 人懐っこい生徒 | |
| naughty student | やんちゃな生徒 | 悪さをする子だが、軽いニュアンス |
| introvert | 内向的な人 | |
| extrovert | 外向的な人 | |

答え方：`I was a bookworm.` / `I was the class clown.` / `I was a sleepy student.`

📌 class clown / class leader は「そのクラスに1人」の役割なので **the** が付きやすい。a bookworm や a troublemaker は「そういうタイプ」なので **a**。

### 🎯 語彙②：フランス・社会の話題
| 英語 | 日本語 | 補足 |
|---|---|---|
| riot(s) | 暴動 | 複数形で使うことが多い |
| strike(s) | ストライキ | go on strike＝ストをする |
| rebellious | 反抗的な | 名詞は rebellion（反乱）、rebel（反逆者） |
| La bise | フランス式の頬キス挨拶 | 頬を合わせて挨拶する習慣 |
| theme park | テーマパーク | amusement park と同じ仲間 |

`We are setting schools on fire.`（学校に火をつけている）
- set ~ on fire ＝ 〜に火をつける（set fire to ~ も同じ意味）
- set - set - set の不規則変化（形が変わらない）
- 国の気質（riots / strikes / rebellious country）の流れで出た冗談か自虐だと思われる

### 🎯 表現①：be famous for ~（〜で有名）
| 例文 | 日本語 |
|---|---|
| We are famous for delicious food. | 私たちは美味しい食べ物で有名です |

📌 be famous for + 名詞。例：`Osaka is famous for takoyaki.`

### 🎯 表現②：Is it well paid?（給料はいい？）
「I wanna be a casino dealer」への質問として出た。

| 表現 | ニュアンス |
|---|---|
| Is it well paid? | 給料はいい？（well-paid と書くこともある） |
| Does it pay well? | 同じ意味の言い換え（より会話的） |
| The pay is good. | 答え方の例 |

### 🎯 文法：used to の疑問・否定
| 形 | 例文 |
|---|---|
| 肯定 | I used to play baseball. |
| 否定 | I didn't use to play baseball. |
| 疑問 | Did you use to play baseball? |

📌 did が付くと used ではなく **use**（d なし）に戻る。
`Did you use to be the class clown?`（昔はクラスのお調子者だった？）

### 🎯 その他
- `Could you dye your hair?` dye ＝ 染める。学校の校則の話だと思われる。過去の話なので「髪を染めてもよかった？」の意味
- ALT ＝ Assistant Language Teacher（外国語指導助手）。日本の学校の話題で出たと思われる（文脈は要確認）
- `I'm 25 years old.` → 会話では `I'm 25.` だけでも自然
- `I like hiking, sports, anime, tattoos and BTS.` 好きなもの全般を並べるときは複数形が自然
- `I'm French.` 国籍は大文字始まり

### 📌 このレッスンのポイントまとめ
- 学生タイプは `I was a/the + 名詞`。「1人の役割」なら the、「タイプ」なら a

## ㉖ Lesson / 10月8日
**テーマ：挨拶の返し方 ／ 現在完了形（Present Perfect）の導入**
※日付はメモに無く、受講者の指定で10/8とした。

### 🎯 挨拶：近況の聞き方と返し方
| 質問 | 意味 |
|---|---|
| How have you been? | 最近どうしてた？（久しぶりに会った相手に） |
| How's your day going? | 今日はどんな感じ？（今日一日の途中経過） |

| 返事 | ニュアンス |
|---|---|
| It's going well. | 順調 |
| It's okay. | まあまあ |
| It's busy. | 忙しい |

📌 How have you been? は現在完了形そのもの（have + been）。「前に会った時から今まで」の期間を聞いている。
- How are you? → I'm good.（今この瞬間）
- How have you been? → I've been busy.（会わなかった間ずっと）

📌 How's your day going? は現在進行形。今日がまだ終わっていないタイミングで使う。終わった後なら How was your day?

### 🎯 現在完了形：have / has + 過去分詞
主語が he / she / it のときだけ **has**、それ以外は **have**。

| 用法 | 意味 | 例文 |
|---|---|---|
| 経験 | 〜したことがある | I have been to Okinawa. / Have you ever eaten mazesoba? |
| 継続 | ずっと〜している | I have lived in Osaka for 20 years. |
| 完了・結果 | もう〜した、今その結果がある | I have just finished my homework. |

否定・疑問：
- 否定：`I haven't tried camping.` / `I have never been to Sukiya.`
- 疑問：`Have you ever watched all of the Ghibli movies?`

| 語 | 意味 | 例 |
|---|---|---|
| ever | これまでに（疑問文） | Have you ever ridden an elephant? |
| never | 一度も〜ない | I have never been to an English speaking country. |
| just | ちょうど | I've just arrived. |
| already / yet | もう / まだ | I haven't finished yet. |
| for + 期間 | 〜の間 | for three years |
| since + 起点 | 〜から | since 2021 |

### 🎯 現在完了 vs 過去形
| 現在完了 | 過去形 |
|---|---|
| I have been to Okinawa.（経験として。いつかは問題にしない） | I went to Okinawa last year.（過去の一点がはっきりしている） |

📌 last year / yesterday / in 2024 / ago のような**過去の時点を示す語**があれば過去形。現在完了とは一緒に使えない。
- ❌ I have been to Okinawa last year.
- ✅ I went to Okinawa last year.

**been と gone の違い**
- `He has been to Osaka.`（行ったことがある。今はここにいる）
- `He has gone to Osaka.`（行ってしまった。今ここにいない）

### 🎯 過去分詞
| 原形 | 過去形 | 過去分詞 |
|---|---|---|
| be | was/were | been |
| go | went | gone |
| do | did | done |
| drink | drank | drunk |
| hold | held | held |
| ride | rode | ridden |
| eat | ate | eaten |
| see | saw | seen |

### 🎯 語彙：osmanthus（金木犀）
メモの "Osmanthas" は osmanthus が正しい綴り（-us）。

| 英語 | 日本語 |
|---|---|
| osmanthus | 金木犀（キンモクセイ） |
| fragrant | 香りのよい |

季節ネタ（秋の香り）で出たものと思われるが、メモに文脈が無い。
- `The osmanthus is in bloom.`（金木犀が咲いている）
- `I love the smell of osmanthus in autumn.`

### 🎯 ideal
ideal は「理想の」という形容詞。ideal for ~（〜に最適な）も使える。例：`This is an ideal place for travelling.`

### 🔤 語彙・表現整理
| 英語 | 日本語 |
|---|---|
| How have you been? | 最近どうしてた？ |
| How's your day going? | 今日はどんな感じ？ |
| It's going well. | 順調です |
| It's busy. | 忙しいです |
| osmanthus | 金木犀 |
| present perfect | 現在完了形 |
| past participle | 過去分詞 |
| have been to / have gone to | 行ったことがある / 行ってしまった |

### 💬 会話練習用
- How have you been?
- How's your day going?
- Have you ever been to Kyoto?
- How long have you lived in Osaka?
- What have you been into lately?

### 📌 このレッスンのポイントまとめ
- 現在完了は have / has + 過去分詞。用法は経験・継続・完了
- last year などの過去の時点を示す語があれば過去形
- have been to（行ったことがある）と have gone to（行ってしまった）の違い
- How are you?（今の調子）と How have you been?（これまでの期間）は別物

## ㉗ Lesson / 10月13日
**テーマ：仮定の質問（What if ~?）／ 条件文（If + 現在形 → will、If + 過去形 → would）**

### 🎯 核心：条件文は2種類ある
| 種類 | 形 | 使う場面 |
|---|---|---|
| 現実的な条件 | If + 現在形, will + 原形 | 実際に起こりうる話 |
| 非現実的な仮定 | If + 過去形, would + 原形 | ありえない・想像の話 |

| 文 | 意味 |
|---|---|
| If I win the lottery, I will buy a car. | 宝くじが当たったら車を買う（起こりうる前提） |
| If I won the lottery, I would buy a car. | 仮に当たったら車を買うだろう（想像の話） |

📌 過去形を使っても「過去の話」ではない。現実から距離を置く（ありえなさを出す）ための形で、仮定法過去と呼ぶ。
📌 宝くじのように確率が低い話は If I won ~, I would ~ が自然。I'd の 'd は would の短縮形。

### 🎯 What if ~?（もし〜だったらどうする？）
| 質問 | 時制 | 想定 | 答え方 |
|---|---|---|---|
| What if you get a new, scary coworker? | 現在形 | 起こりうる | I will ~ |
| What if you find a wallet outside? | 現在形 | 起こりうる | I will ~ |
| What if you lose your phone? | 現在形 | 起こりうる | I will ~ |
| What if you got Isekai'd? | 過去形 | ありえない | I would ~ |
| What if you were king of the world for one day? | 過去形 | ありえない | I would ~ |

メモ内の訂正：
- ❌ What if you found a wallet outside? → ✅ What if you find a wallet outside?（財布を拾うのは起こりうるので現在形）

📌 質問が現在形なら will、過去形なら would で答える。質問の時制と答えの助動詞をそろえる。
📌 仮定法では主語が I / he / she / it でも **were** を使うのが基本（If I were king of the world, I would ~）。会話では If I was ~ もよく聞く。

### 🎯 語彙：現実編（I will ~）
| 英語 | 日本語 | 補足 |
|---|---|---|
| get him fired | 彼をクビにさせる | get + 人 + 過去分詞 で「〜される状態にする」 |
| keep my distance | 距離を置く | keep one's distance (from ~) |
| bring backup | 助っ人を連れてくる | backup＝加勢・応援（不可算名詞） |
| hand in ~ | 〜を提出する・届ける | hand it in to the police（警察に届ける） |
| take it gambling | ギャンブルに持っていく | go gambling と同じ形（go/take + ~ing） |
| check inside | 中を確認する | |
| retrace my steps | 来た道をたどり直す | 無くしものの定番表現 |
| ask AI for help | AIに助けを求める | ask + 人/物 + for help |
| use my laptop to call my phone | ノートPCで自分のスマホに電話する | use A to + 動詞 |

メモ内の訂正：
- ❌ It will hand it in to the police. → ✅ **I** will hand it in to the police.

📌 `I will get him fired.` は使役の形。`I will fire him.`（自分が解雇する）と違い、自分が手を下さず誰かにクビにさせるニュアンス。

### 🎯 語彙：想像編（I would ~）
| 英語 | 日本語 | 補足 |
|---|---|---|
| Isekai'd | 異世界に飛ばされた | isekai（異世界）を動詞化した口語 |
| slime | スライム | RPGのモンスター |
| hunt | 狩る | hunter（狩人）と同じ語源 |
| catgirl | 猫耳の女の子 | アニメ・ゲーム系の俗語 |
| make rules | ルールを作る | |
| benefit | 利益を与える | rules that benefit me |
| expensive | 高価な | |

📌 `I would stop the war between Russia and Ukraine.` メモは Russian だったが、国は **Russia**、人や形容詞が Russian。
📌 `rules that benefit me` の that は関係代名詞。主語が複数名詞 rules なので benefit（benefits ではない）。
📌 `lots of expensive food` の lots of は a lot of よりくだけた響き。

### 🎯 if の話し方
| 表現 | ニュアンス |
|---|---|
| If I win ~, I will ~ | 可能性がある。本気の予定に近い |
| If I won ~, I would ~ | 仮定。夢の話 |
| What if ~? | 「もし〜なら？」と気軽に相手に聞く |
| What would you do if ~? | 「もし〜ならどうする？」の標準的な形 |

- What would you do if you lost your phone?
- What would you do if you were king of the world?

### 🔤 語彙・表現整理
| 英語 | 日本語 |
|---|---|
| What if ~? | もし〜だったらどうする？ |
| If + 過去形, would ~ | 仮定法過去 |
| win the lottery | 宝くじに当たる |
| coworker | 同僚 |
| scary | 怖い |
| get him fired | 彼をクビにさせる |
| keep my distance | 距離を置く |
| bring backup | 助っ人を連れてくる |
| hand in | 届ける・提出する |
| retrace my steps | 来た道をたどり直す |
| Isekai'd | 異世界に飛ばされた |
| hunt | 狩る |
| benefit | 利益を与える |

### 💬 会話練習用
- If you won the lottery, what would you buy?
- What if you get a new, scary coworker?
- What would you do if you found a wallet outside?
- What if you lose your phone?
- What if you were king of the world for one day?

### 📌 このレッスンのポイントまとめ
- 起こりうる話 → If + 現在形, will
- ありえない仮の話 → If + 過去形, would
- What if の後ろの時制が、答えの will / would を決める
- 国名と国籍：Russia（国）と Russian（人・形容詞）
