## ㉖ Lesson / 10月8日
**テーマ：挨拶の返し方 ／ 現在完了形（Present Perfect）の導入**
講師：YUTA
※日付はメモに無く、受講者の指定で10/8とした。

### 🎯 挨拶：近況の聞き方と返し方
| 質問 | 意味 |
|---|---|
| How have you been? | 最近どうしてた？（久しぶりに会った相手に） |
| How's your day going? | 今日はどんな感じ？（今日一日の途中経過） |

| 返事 | ニュアンス |
|---|---|
| It's going well. | 順調 |
| It's okay. | まあまあ |
| It's busy. | 忙しい |

📌 How have you been? は現在完了形そのもの（have + been）。「前に会った時から今まで」の期間を聞いている。
- How are you? → I'm good.（今この瞬間）
- How have you been? → I've been busy.（会わなかった間ずっと）

📌 How's your day going? は現在進行形。今日がまだ終わっていないタイミングで使う。終わった後なら How was your day?

### 🎯 現在完了形：have / has + 過去分詞
主語が he / she / it のときだけ **has**、それ以外は **have**。

| 用法 | 意味 | 例文 |
|---|---|---|
| 経験 | 〜したことがある | I have been to Okinawa. / Have you ever eaten mazesoba? |
| 継続 | ずっと〜している | I have lived in Osaka for 20 years. |
| 完了・結果 | もう〜した、今その結果がある | I have just finished my homework. |

否定・疑問：
- 否定：`I haven't tried camping.` / `I have never been to Sukiya.`
- 疑問：`Have you ever watched all of the Ghibli movies?`

| 語 | 意味 | 例 |
|---|---|---|
| ever | これまでに（疑問文） | Have you ever ridden an elephant? |
| never | 一度も〜ない | I have never been to an English speaking country. |
| just | ちょうど | I've just arrived. |
| already / yet | もう / まだ | I haven't finished yet. |
| for + 期間 | 〜の間 | for three years |
| since + 起点 | 〜から | since 2021 |

### 🎯 現在完了 vs 過去形
| 現在完了 | 過去形 |
|---|---|
| I have been to Okinawa.（経験として。いつかは問題にしない） | I went to Okinawa last year.（過去の一点がはっきりしている） |

📌 last year / yesterday / in 2024 / ago のような**過去の時点を示す語**があれば過去形。現在完了とは一緒に使えない。
- ❌ I have been to Okinawa last year.
- ✅ I went to Okinawa last year.

**been と gone の違い**
- `He has been to Osaka.`（行ったことがある。今はここにいる）
- `He has gone to Osaka.`（行ってしまった。今ここにいない）

### 🎯 過去分詞
| 原形 | 過去形 | 過去分詞 |
|---|---|---|
| be | was/were | been |
| go | went | gone |
| do | did | done |
| drink | drank | drunk |
| hold | held | held |
| ride | rode | ridden |
| eat | ate | eaten |
| see | saw | seen |

### 🎯 語彙：osmanthus（金木犀）
メモの "Osmanthas" は osmanthus が正しい綴り（-us）。

| 英語 | 日本語 |
|---|---|
| osmanthus | 金木犀（キンモクセイ） |
| fragrant | 香りのよい |

季節ネタ（秋の香り）で出たものと思われるが、メモに文脈が無い。
- `The osmanthus is in bloom.`（金木犀が咲いている）
- `I love the smell of osmanthus in autumn.`

### 🎯 ideal
ideal は「理想の」という形容詞。ideal for ~（〜に最適な）も使える。例：`This is an ideal place for travelling.`

### 🔤 語彙・表現整理
| 英語 | 日本語 |
|---|---|
| How have you been? | 最近どうしてた？ |
| How's your day going? | 今日はどんな感じ？ |
| It's going well. | 順調です |
| It's busy. | 忙しいです |
| osmanthus | 金木犀 |
| present perfect | 現在完了形 |
| past participle | 過去分詞 |
| have been to / have gone to | 行ったことがある / 行ってしまった |

### 💬 会話練習用
- How have you been?
- How's your day going?
- Have you ever been to Kyoto?
- How long have you lived in Osaka?
- What have you been into lately?

### 📌 このレッスンのポイントまとめ
- 現在完了は have / has + 過去分詞。用法は経験・継続・完了
- last year などの過去の時点を示す語があれば過去形
- have been to（行ったことがある）と have gone to（行ってしまった）の違い
- How are you?（今の調子）と How have you been?（これまでの期間）は別物

## ㉗ Lesson / 10月13日
**テーマ：仮定の質問（What if ~?）／ 条件文（If + 現在形 → will、If + 過去形 → would）**

### 🎯 核心：条件文は2種類ある
| 種類 | 形 | 使う場面 |
|---|---|---|
| 現実的な条件 | If + 現在形, will + 原形 | 実際に起こりうる話 |
| 非現実的な仮定 | If + 過去形, would + 原形 | ありえない・想像の話 |

| 文 | 意味 |
|---|---|
| If I win the lottery, I will buy a car. | 宝くじが当たったら車を買う（起こりうる前提） |
| If I won the lottery, I would buy a car. | 仮に当たったら車を買うだろう（想像の話） |

📌 過去形を使っても「過去の話」ではない。現実から距離を置く（ありえなさを出す）ための形で、仮定法過去と呼ぶ。
📌 宝くじのように確率が低い話は If I won ~, I would ~ が自然。I'd の 'd は would の短縮形。

### 🎯 What if ~?（もし〜だったらどうする？）
| 質問 | 時制 | 想定 | 答え方 |
|---|---|---|---|
| What if you get a new, scary coworker? | 現在形 | 起こりうる | I will ~ |
| What if you find a wallet outside? | 現在形 | 起こりうる | I will ~ |
| What if you lose your phone? | 現在形 | 起こりうる | I will ~ |
| What if you got Isekai'd? | 過去形 | ありえない | I would ~ |
| What if you were king of the world for one day? | 過去形 | ありえない | I would ~ |

メモ内の訂正：
- ❌ What if you found a wallet outside? → ✅ What if you find a wallet outside?（財布を拾うのは起こりうるので現在形）

📌 質問が現在形なら will、過去形なら would で答える。質問の時制と答えの助動詞をそろえる。
📌 仮定法では主語が I / he / she / it でも **were** を使うのが基本（If I were king of the world, I would ~）。会話では If I was ~ もよく聞く。

### 🎯 語彙：現実編（I will ~）
| 英語 | 日本語 | 補足 |
|---|---|---|
| get him fired | 彼をクビにさせる | get + 人 + 過去分詞 で「〜される状態にする」 |
| keep my distance | 距離を置く | keep one's distance (from ~) |
| bring backup | 助っ人を連れてくる | backup＝加勢・応援（不可算名詞） |
| hand in ~ | 〜を提出する・届ける | hand it in to the police（警察に届ける） |
| take it gambling | ギャンブルに持っていく | go gambling と同じ形（go/take + ~ing） |
| check inside | 中を確認する | |
| retrace my steps | 来た道をたどり直す | 無くしものの定番表現 |
| ask AI for help | AIに助けを求める | ask + 人/物 + for help |
| use my laptop to call my phone | ノートPCで自分のスマホに電話する | use A to + 動詞 |

メモ内の訂正：
- ❌ It will hand it in to the police. → ✅ **I** will hand it in to the police.

📌 `I will get him fired.` は使役の形。`I will fire him.`（自分が解雇する）と違い、自分が手を下さず誰かにクビにさせるニュアンス。

### 🎯 語彙：想像編（I would ~）
| 英語 | 日本語 | 補足 |
|---|---|---|
| Isekai'd | 異世界に飛ばされた | isekai（異世界）を動詞化した口語 |
| slime | スライム | RPGのモンスター |
| hunt | 狩る | hunter（狩人）と同じ語源 |
| catgirl | 猫耳の女の子 | アニメ・ゲーム系の俗語 |
| make rules | ルールを作る | |
| benefit | 利益を与える | rules that benefit me |
| expensive | 高価な | |

📌 `I would stop the war between Russia and Ukraine.` メモは Russian だったが、国は **Russia**、人や形容詞が Russian。
📌 `rules that benefit me` の that は関係代名詞。主語が複数名詞 rules なので benefit（benefits ではない）。
📌 `lots of expensive food` の lots of は a lot of よりくだけた響き。

### 🎯 if の話し方
| 表現 | ニュアンス |
|---|---|
| If I win ~, I will ~ | 可能性がある。本気の予定に近い |
| If I won ~, I would ~ | 仮定。夢の話 |
| What if ~? | 「もし〜なら？」と気軽に相手に聞く |
| What would you do if ~? | 「もし〜ならどうする？」の標準的な形 |

- What would you do if you lost your phone?
- What would you do if you were king of the world?

## ㉘ Lesson / 10月15日
**テーマ：ダイエット・食事の話 / neither・either で「私も」と返す**
※日付はメモに無く、まとめた日（10/15）で記載。メモは単語の羅列が中心のため、授業で出た語句と補足を分けた。**（補足）と付いた例文・説明は授業で出たものではなく、学習用に追加したもの。**

### 🎯 表現①：be used to ~（〜に慣れている）
授業で出た文：`I'm used to it.`（それには慣れてるよ）

| 形 | 意味 | 例文 |
|---|---|---|
| be used to + 名詞 / ~ing | 〜に慣れている | I'm used to it. / I'm used to getting up early.（補足） |
| used to + 原形 | 昔は〜した | I used to play baseball. |

📌（補足）見た目は似ているが別物。**to の後ろが名詞か ~ing なら「慣れている」**、原形なら「昔は〜した」。
📌（補足）「慣れていく」変化は get used to ~（I'm getting used to it.）。

### 🎯 語彙：ダイエット・食事
| 英語 | 日本語 | 補足 |
|---|---|---|
| diet | ダイエット／日頃の食事 | 「減量」だけでなく「普段の食事内容」の意味もある |
| lose weight | 体重を減らす | 反対は gain weight（体重が増える） |
| meal prep | 食事の作り置き・準備 | meal preparation の略。名詞扱い |
| healthy | 健康的な | |

授業で出た文：
- `My diet is healthy.`（私の食事は健康的です）
- `I do meal prep.`（作り置きをしています）

（補足）
- `I'm trying to lose weight.`（減量しようとしています）

📌（補足）diet は文脈で意味が変わる。`I'm on a diet.`（ダイエット中）と `My diet is healthy.`（普段の食事が健康的）を区別する。
📌（補足）meal prep の動詞は do / make。`I do meal prep on Sundays.`

### 🎯 文法：neither / either / same（「私も」の返し方）
相手の発言に同意するときの形は、**相手の文が肯定か否定か**で変わる。

| 相手の文 | 「私も」の返し方 | 例 |
|---|---|---|
| 肯定（I like sushi.） | So do I. / Me too. / Same here. | So do I. |
| 否定（I don't like cilantro.） | **Neither do I.** / Me neither. / I don't either. | Neither do I. |

授業で出た文：`Neither have I.` / `Neither can I.`

（補足）相手の発言との組み合わせ例：
- `I haven't been to Kyoto.` → `Neither have I.`（私もない）
- `I can't swim.` → `Neither can I.`（私もできない）

📌 **Neither + 助動詞 + 主語** の語順（疑問文と同じ並び）。
📌 助動詞は**相手の文に合わせる**。
- I haven't ~ → Neither **have** I
- I can't ~ → Neither **can** I
- I don't ~ → Neither **do** I
- I didn't ~ → Neither **did** I

📌 neither 自体が否定の意味を含むので、後ろに not は付けない。❌ Neither don't I.
📌 either は文末に置く：`I don't like it either.`（私も好きじゃない）。肯定文には使えない。
📌 same は `Same here.`（こっちも同じ）のように、肯定・否定どちらにも使える便利な返事。

### 🎯 表現②：You won't be able to make it on time.
| 部分 | 意味 |
|---|---|

| Do you ever ~? | 〜することはある？ |

- （補足）go out with は「付き合う」の意味もある（`He's going out with her.`）。文脈で判断する。

## ㉙ Lesson / 10月15日
**テーマ：「〜すればするほど…」（the 比較級, the 比較級）／ 習慣・刺激を受ける表現**
※日付と講師名はメモに無く、日付はまとめた日（10/15）で記載。**（補足）と付いた例文・説明は授業で出たものではなく、学習用に追加したもの。**

### 🎯 核心：the + 比較級 + S + V, the + 比較級 + S + V
意味：**〜すればするほど、ますます…になる**

| 型 | 内容 |
|---|---|
| The + 比較級 + S + V, | 前半（条件・原因側）：〜すればするほど |
| the + 比較級 + S + V. | 後半（結果側）：…になる |

📌 前半・後半とも、**比較級を先頭に出して the を付ける**。普通の文の語順（I get older.）から、比較級だけを前に引っ張り出した形。
- 元の文：`I get **older**. Time goes **faster**.`
- 変形後：`**The older** I get, **the faster** time goes.`

📌 この the は「その分だけ」という意味の特別な the で、冠詞の the とは別物。
📌 口語では動詞が省略されることもある。（補足）`The more, the better.`（多ければ多いほどいい）

### 🎯 授業で出た例文
| 英語 | 日本語 | ポイント |
|---|---|---|
| The older I get, the faster time goes. | 年をとるほど、時間が早く過ぎる | older（old の比較級）／faster（fast の比較級） |
| The farther I go, the more money I get. | 遠くへ行くほど、お金がもらえる | farther／more money（more + 名詞） |
| The more I study English, the better I speak. | 英語を勉強するほど、うまく話せる | better（well の比較級） |
| The more I gamble, the more money I lose. | ギャンブルをするほど、お金を失う | more + 名詞 |
| The busier I am, the faster I finish work. | 忙しいほど、仕事が早く終わる | busier（busy の比較級） |
| The more I practice, the busier I get. | 練習するほど、忙しくなる | busier／get + 形容詞 |
| The more I use AI, the lazier I become. | AIを使うほど、怠け者になる | lazier／become + 形容詞 |

メモ内の訂正：
- ❌ the more I **learn study** English → ✅ the more I **study** English（learn か study のどちらか1つ）
- ❌ the busier I **work** → ✅ the busier I **am**（busy は形容詞なので be 動詞か get と使う。work は動詞）。 `The busier I get, the faster I finish work.` も自然
- メモにある `The time goes faster than when I was young.`（若い頃より時間が早く過ぎる）は、**than を使う普通の比較文**。the 比較級の型ではない。the を付けた2つ目の例（The older I get ~）と見比べると、型の違いが分かる

### 🎯 比較級の作り方（補足）
| 元の語 | 比較級 | 授業の例 |
|---|---|---|
| old | older | the older I get |
| fast | faster | the faster time goes |
| far | farther / further | the farther I go |
| busy | busier（y → ier） | the busier I am |
| lazy | lazier（y → ier） | the lazier I become |
| well（上手に） | better | the better I speak |
| much / many | more | the more money I lose |
| difficult など長い語 | more difficult | The more difficult it is, the more fun it is.（補足） |

📌（補足）farther は主に「距離」、further は「程度・それ以上」に使う。会話では farther / further どちらもよく聞く。
📌（補足）well の比較級が better、good の比較級も better。`I speak better.`（より上手に話す）は副詞の better、`a better speaker`（より良い話し手）は形容詞の better。

### 🎯 語彙：習慣
| 英語 | 日本語 | 補足 |
|---|---|---|
| habit | 習慣・くせ | good habit（良い習慣）／bad habit（悪いくせ） |

質問文：`What is a good habit that you have been doing this year?`（今年やってきた良い習慣は？）
- `have been doing` は「ずっと〜してきた」の形（現在完了進行形）
- that は関係代名詞（a good habit を説明している）
- （補足）答え方の例：`I've been walking every morning this year.` / `I've been doing meal prep every Sunday.`

### 🎯 語彙：刺激を受ける・気になる
| 英語 | 日本語 | 補足 |
|---|---|---|
| I'm inspired by you. | あなたに刺激を受けた | inspired ＝ 刺激を受けた（受け手） |
| I'm motivated by you. | あなたのおかげでやる気が出た | motivated ＝ やる気が出た（受け手） |
| You are inspiring. | あなたは刺激的な人だ | inspiring ＝ 人に刺激を与える（与え手） |
| I'm a curious person. | 好奇心旺盛な人です | |
| I'm curious. | 気になる！ | curious ＝ 知りたい、気になる |

📌 **-ed は「受け手の気持ち」、-ing は「与え手の性質」**。
- `I am inspired by you.`（私が刺激を受けた）
- `You are inspiring.`（あなたが刺激を与える人だ）

📌（補足）「〜が気になる」は `I'm curious about ~`。例：`I'm curious about your habit.`
📌（補足）`curious` は「好奇心旺盛」という良い意味。「詮索好き」のニュアンスは nosy。

### 🎯 表現：できなかった状態が続いている
`I haven't been able to wake up early.`（早起きできていない）
- have been able to ＝ 「できる」の現在完了（今までずっと〜できている／いない）
- 否定にすると「今までずっとできていない」というニュアンス
- （補足）`I can't wake up early.`（早起きができない）より、「最近ずっとできていない」を強調できる

### 🎯 語彙：朝型・夜型
| 英語 | 日本語 | 補足 |
|---|---|---|
| morning person | 朝型の人 | 授業のメモは "morning bird" と書かれていたが、一般的には **early bird / morning person** |
| early bird | 早起きの人 | |
| night owl | 夜型の人 | owl（フクロウ）は夜行性 |

メモ内の訂正：
- ❌ morning bird → ✅ **early bird** または **morning person**（morning bird という定型表現は一般的ではない）
- （補足）`I'm a morning person.` / `I'm a night owl.`

### 🔤 語彙・表現整理
| 英語 | 日本語 |

| The 比較級 S V, the 比較級 S V | 〜すればするほど… |

## ㉚ Lesson / 10月20日
**テーマ：Life in the future（100年後の未来）／ 未来の予想を話す表現**
講師：Louise
※日付はメモに無く、まとめた日（10/20）で記載。**（補足）と付いた例文・説明は授業で出たものではなく、学習用に追加したもの。**

### 🎯 核心：未来の予想を言う（will / gonna / will be able to）
| 形 | 意味 | 授業で出た文 |
|---|---|---|
| will + 原形 | 〜だろう（予想） | We will have floating cities. |
| will not (won't) + 原形 | 〜ないだろう | There won't be pianos in the future. |
| be gonna + 原形 | 〜になるだろう（口語） | Life is gonna be worse because of climate change. |
| will be able to + 原形 | 〜できるようになるだろう | We will be able to teleport. |
| will be + 過去分詞 | 〜されるだろう（受け身） | I think a lot of humans will be gone / replaced by AI. |

📌 gonna ＝ going to の口語。話し言葉専用で、書くときは going to。
📌 未来の「できる」は will can ではなく **will be able to**。
📌 In 100 years ＝ 今から100年後（in + 期間 ＝ 〜後に）。

メモ内の訂正：
- ❌ In **a** 100 years → ✅ In 100 years（または In a hundred years）
- ❌ a lot of **human** → ✅ a lot of **humans**（人類全体なら humankind / humanity）
- ❌ Will we drive flying **car**? → ✅ Will we drive flying **cars**?（「空飛ぶ車全般」なので複数形）
- ❌ Replaced by AI（単独）→ ✅ Humans will be replaced by AI（受け身は主語と be 動詞が必要）

### 🎯 授業で出た例文
| 英語 | 日本語 | ポイント |
|---|---|---|
| Life is gonna be worse because of climate change. | 気候変動のせいで生活は悪くなる | because of + 名詞 |
| Temperature is getting higher. | 気温が上がってきている | 現在進行形で「変化の途中」 |
| I think a lot of humans will be gone. | 多くの人間がいなくなると思う | be gone ＝ いなくなる |
| (Humans will be) replaced by AI. | AIに取って代わられる | replace ＝ 置き換える |
| We will have floating cities. | 空に浮かぶ都市ができる | floating ＝ 浮かんでいる |
| We will be able to teleport. | 瞬間移動できるようになる | teleport ＝ 瞬間移動する |
| AI can replace my job. | AIは私の仕事を代われる | |
| There won't be pianos in the future. | 未来にはピアノはなくなる | There will be / There won't be |
| People can make music through AI. | 人はAIを通して音楽を作れる | |
| It's already happening. | もう起こっている | already ＝ もう・すでに |
| Do you think robots will try to kill us? | ロボットは私たちを殺そうとすると思う？ | try to + 原形 |
| We won't be alive. / It won't affect us. | 私たちは生きていない／影響しない | |
| I want to know something that nobody knows. | 誰も知らないことを知りたい | something that + 動詞 |

📌 温度の変化は Temperature is getting higher.（進行中の変化）。（補足）`Temperatures are rising.` とも言う。
📌 affect と effect：**affect ＝ 動詞（影響する）**、effect ＝ 名詞（影響・効果）。`It won't affect us.`
📌（補足）`AI can replace my job.` は事実の言い方。可能性なら `AI might replace my job.` と言うと弱める。
📌（補足）`through AI` は「AIを通して」。道具として使うなら `with AI` / `using AI` も自然。
